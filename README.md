# وکس بارتر — Vex Barter

وب‌سایت شرکتی چندصفحه‌ای در حوزه **معاوضه و تهاتر کسب‌وکارها**، ساخته‌شده با React و Vite.

---

## ۲. نصب و اجرا

پیش‌نیاز: Node.js نسخه ۱۸ یا بالاتر.

```bash
cd vex-barter
npm install
```

### حالت توسعه

```bash
npm run dev
```

سرور توسعه روی `http://localhost:5173` بالا می‌آید.

### ساخت نسخه نهایی

```bash
npm run build
```

خروجی در پوشه `dist/` ساخته می‌شود.

### پیش‌نمایش نسخه نهایی

```bash
npm run preview
```

پیش‌نمایش روی `http://localhost:4173` اجرا می‌شود.

## ۳. نکته‌ها

- **RTL:** سراسر سایت راست‌به‌چپ است (`dir="rtl"` در `index.html`).
- **پالت رنگ:** پس‌زمینه سرمه‌ای `#0f172a`، تأکید اصلی سبز زمردی `#10b981`، متن سفید `#ffffff`، تأکید ثانویه کهربایی `#f59e0b`. سطوح کارت‌ها از سفید با شفافیت ۵٪ روی زمینه سرمه‌ای ساخته می‌شوند.
- **لوگو و آیکون:** لوگو از `public/logo.png` و فاویکون از `public/favicon.ico` بارگذاری می‌شود.
- **بدون فرم:** طبق درخواست، هیچ فرمی در سایت وجود ندارد؛ صفحه تماس فقط راه‌های ارتباطی را نمایش می‌دهد.
- **بدون داده ساختگی:** هیچ آمار، لوگوی مشتری یا نام افراد اختراع نشده است.
- **مسیرها:** روتینگ با `react-router-dom` انجام می‌شود؛ برای استقرار روی سرور، روتینگ باید به `index.html` بازنویسی شود.
